. *Enable MEM repositories*
+
====

Use the following command to add the MEM repositories:

[literal,subs="quotes"]
----
# zypper addrepo -f http://builds.midonet.org/midonet-5/stable/sles12/ midonet
----
[literal,subs="quotes"]
----
# zypper addrepo -f http://builds.midonet.org/openstack-liberty/stable/sles12/ midonet-plugin-liberty
----

[NOTE]
Replace *_username_* and *_password_* with the login credentials provided by
Midokura.
====
