= MidoNet Cluster Installation

. *Install MidoNet Cluster package*
+
====
[source]
----
# yum install midonet-cluster
----
====

. *Configure MidoNet API*
+
====

Refer to xref:authentication[] for authentication options.

Set the ZooKeeper hosts in /etc/midonet/midonet.conf by ensuring that
the zookeeper.zookeeper_hosts property has the IPs of all the ZooKeeper
hosts:

[literal,subs="verbatim,quotes"]
----
zookeeper.zookeeper_hosts = **_nsdb1_**:2181,*_nsdb2_*:2181,*_nsdb3_*:2181
----

. *Start MidoNet Cluster*
+
====
[source]
----
# systemctl enable midonet-cluster.service
# systemctl start midonet-cluster.service
----
====
